# Apex Operations Dashboard

Enterprise operations console built with Next.js App Router and TypeScript.

## Overview

Apex Operations Dashboard provides visibility into operational performance, service availability, real-time activity audit streams, and preference management.

## Features

- **Executive Summary**: Key business metrics and KPIs (Revenue, Subscriptions, Churn, SLA Uptime).
- **Recent Activity**: Live audit stream tracking deployments, billing transactions, and system updates.
- **Quick Operations**: One-click actions for system snapshots, feed syncing, and checksum validations.
- **Reports & Archives**: Access to export active feeds and inspect archived audit logs.
- **Preferences & Diagnostics**: Console customization settings and subsystem status monitoring.

## Getting Started

### Prerequisites

- Node.js 20+
- npm

### Installation & Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```
